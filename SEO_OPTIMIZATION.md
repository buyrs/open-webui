## Usage

### Using Page-Based SEO (Recommended)
```svelte
<script lang="ts">
  import SEO from '$lib/components/SEO.svelte';
  import { page } from '$app/stores';

  $: lang = ($page.url.searchParams.get('lang') || 'fr') as 'fr' | 'en' | 'de' | 'nl' | 'pt' | 'pt-BR' | 'es' | 'ar';
</script>

<SEO page="home" {lang} />
```

### Using Custom SEO Override
```svelte
<script>
  import SEO from '$lib/components/SEO.svelte';
</script>

<SEO
  title="Custom Title"
  description="Custom description"
  keywords="custom, keywords"
/>
```

### Supported Page Keys
- `home` - Home/Chat page
- `billing` - Billing page
- `settings` - Account Settings
- `receipt` - Receipt Settings
- `card` - Card Preview
- `audit` - Audit Log
- `members` - Members Directory

### Supported Language Codes
- `fr` - Français (default)
- `en` - English
- `de` - Deutsch
- `nl` - Nederlands
- `pt` - Português
- `pt-BR` - Português (Brasil)
- `es` - Español
